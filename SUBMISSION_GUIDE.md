# Submission Guide (For Personal Use)

This guide maps each Coursera task (1–9) to the file in this repository that
satisfies it, and explains exactly what to submit once your repository is
pushed to GitHub.

Replace `YOUR_GITHUB_USERNAME` and `YOUR_REPOSITORY_NAME` with your real
values throughout.

---

## Task 1 — README.md

**Coursera asks for:** A README describing the project (simple interest
calculator).

**Repository file:** `README.md`

**What to submit:** The public GitHub URL of the file:

```
https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPOSITORY_NAME/blob/main/README.md
```

## Task 6 — forked-repo

**Coursera asks for:** Proof that your repository is a fork of
`ibm-developer-skills-network/mcino-Introduction-to-Git-and-GitHub`.

**Repository file:** `forked-repo`

**What to submit:** After running the real `curl` command described inside
`forked-repo` and pasting the real output into that file, either:

- Submit the file's public GitHub URL, **or**
- Submit the exact text Coursera requests (check the assignment instructions
  for whether it wants a URL or pasted text)

This requires **real terminal/API evidence** — it cannot be generated in
advance.

---

## Task 7 — merge_branches

**Coursera asks for:** Evidence that you merged the `bug-fix-typo` branch
into `main`, showing that 1 file was changed.

**Repository file:** `merge_branches`

**What to submit:** After running the real merge commands and pasting the
real output into `merge_branches`, submit the file's content or URL as

This requires **real terminal/API evidence** — it cannot be generated in

## Task 8 — bug-fix-revert

**Coursera asks for:** Evidence of a pull request and the forked repository
it was created from.

**Repository file:** `bug-fix-revert`

**What to submit:** After opening a real pull request, running the real
`curl` command, and pasting the real output into `bug-fix-revert`, submit
the file's content or URL as Coursera requests.

This requires **real terminal/API evidence** — it cannot be generated in
advance.

## Task 9 — github-branches

**Coursera asks for:** Evidence of the branches in your repository and their
status.

**Repository file:** `github-branches`

**What to submit:** After running the real `git branch`/`git status`
commands and pasting the real output into `github-branches`, submit the
file's content or URL as Coursera requests.

This requires **real terminal/API evidence** — it cannot be generated in
advance.
